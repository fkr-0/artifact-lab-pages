# Storyboard Studio

A local-first visual story, campaign, and illustrated-document authoring studio. It combines structured narrative blocks, embedded images, live layout controls, and portable exports in one browser-only application.

## Authoring workflow

- Start from a **Visual narrative**, **Character dossier**, **Campaign carousel**, or **Field manual** structure.
- Compose hero, scene, character, image, text, quote, blueprint, slogan, divider, and production-note blocks.
- Edit titles, scene or role metadata, copy, image sources, and accessible image descriptions from the inspector.
- Reorder blocks by dragging them or with the explicit Up/Down controls.
- Filter a large document by block title, type, metadata, or content.
- Apply coordinated **Editorial storyboard**, **Campaign signal**, **Neon pitch deck**, **Technical dossier**, or **Humanist field notes** design systems.
- Independently tune five portable typography systems, six semantic color systems, four image treatments, and compact/balanced/generous spacing rhythms after applying a preset.
- Use poster, grid, zine, or manual layouts with live theme, spacing, custom accent, and preview-zoom controls.
- Enter **Focus** mode for an uncluttered document review.

## Reliability and export

- Changes autosave locally with migration from the original v1 and v2 browser states.
- Undo and redo retain up to 80 document states.
- The document-health bar reports block, word, and image counts, active design treatment, missing image descriptions, and empty blocks.
- Export a self-contained HTML artifact, editable JSON, or Markdown.
- Copy HTML or JSON, and print or save the document as PDF from the browser.
- Imported images remain embedded as data URLs; the application has no backend and uploads nothing.

## Keyboard shortcuts

| Shortcut | Action |
|---|---|
| Ctrl/Command + S | Save the current state locally |
| Ctrl/Command + Z | Undo |
| Ctrl/Command + Shift + Z | Redo |
| Ctrl/Command + D | Duplicate the selected block |
| / | Focus the block filter |
| Delete or Backspace | Delete the selected block when no field is being edited |
| Escape | Close the import dialog or leave Focus mode |

Open `index.html` directly or serve the repository through the artifacts development server.
