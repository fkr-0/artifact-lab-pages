# Storyboard Studio

Client-side single-document builder for mixing illustrations and text into printable/exportable HTML artifacts.

## Features

- Drag and drop images into a local browser session.
- Arrange hero images, image captions, prose blocks, quotes, slogans, and blueprint blocks.
- Switch between poster, grid, zine, and manual layouts.
- Export JSON for later editing.
- Export a self-contained HTML document with embedded data URL images.
- Print or save as PDF from the browser.

The app does not require a backend and does not upload files.
