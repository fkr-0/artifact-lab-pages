Club Ledger

A self-contained one-page financial account tracker for a small club. Paste JSON from the previous round, inspect member obligations and wallet balances, let a trusted user log mutations, then export the new JSON to keep the chain moving.

JSON data

users hold id, name, monthlyFee, activeFrom, optional activeUntil.

wallets hold id, name, currency, openingBalance, optional currentAmount, optional exchangeRateToBase, and transactions.

membership transactions use type: "membership", userId, month, and positive amount. Wallet conversions create linked transfer-out and transfer-in rows with one transferId.

auditLog is now part of the exported data. It records import, trusted mutations, and explicit export actions with date/time, actor, operation, target, and details.
