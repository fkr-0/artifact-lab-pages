# Bathroom Emergency Guide 4.13.1 — deterministic render-tooling patch

## Purpose

Prepare a conservative patch release after 4.13.0. The reader-facing route
content, evidence claims, stable identities, standalone extraction boundaries,
and 60-PDF matrix remain unchanged. The patch removes known build-log noise and
makes the offline chart font environment explicit and testable.

## Patch scope

- Replace unsupported Matplotlib `black` font requests with the available bold
  weight used elsewhere in the diagram system.
- Add a project-local Fontconfig profile for Vega text measurement and
  `rsvg-convert` rasterization.
- Declare that profile in the canonical visualization catalog.
- Load the Fontconfig profile before Vega and its native canvas dependencies.
- Forward successful child-renderer stderr instead of silently discarding it.
- Add a render-tooling validator that rejects unsupported font weights, parses
  the local Fontconfig profile, smoke-renders all eight offline Vega-Lite
  figures, requires an exact SVG/PNG output set, and fails on any stderr.

## Release invariants

- Keep O, A, B, C, D, H, Z, P, T, and R as the ten standalone families.
- Keep six master PDF editions and 60 standalone PDF editions.
- Do not alter route ownership, form ownership, source ownership, or figure
  ownership.
- Do not renumber, reuse, or retire an existing stable public reference.
- Do not change emergency routing, medical claims, legal boundaries, service
  claims, or local deployment assumptions.
- Preserve native MathML, tagged-PDF, color/mono, geometry, accessibility,
  overflow, browser, and release-manifest gates.
- Do not push, publish, deploy, sign, or run the prepared Pages workflow.

## Verification

The release must pass:

1. `python3 bin/validate_render_tooling.py`;
2. a complete diagram build with zero stderr bytes;
3. `npm run build` from the exact implementation revision;
4. an independent `npm test` from that same revision and epoch;
5. representative direct visual inspection of changed graph/route diagrams and
   the master/A standalone page contact sheets;
6. release evidence with artifact hashes, warning state, and explicit
   no-push/no-publish/no-deploy flags.
