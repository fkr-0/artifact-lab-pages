# 4.6.0 Release Architecture

## Purpose

Release 4.6 turns the guide from a complete document plus two pilot subguides
into a maintained deployment system. The release adds writable templates,
stable public references, a complete reference appendix, a project landing
artifact, local installation instructions, and a CI-enforced output matrix.

## Decisions

### Stable typed IDs, not canonical hierarchy numbers

Canonical address:

    [BEG:<owner>:<kind>:<sequence>]

Hierarchical labels such as `calm.1.1.3` remain optional reading aids. They are
not canonical because inserting a section would rename every later address.
Stable IDs remain attached to the resource, and retired IDs are not reused.

### Forms are a subguide, not appendix debris

T — Templates / The Blue Book owns detachable resources. The master includes T
for completeness; the standalone family makes pages easy to print, take, fill,
and replace.

The deployer owns local truth and maintenance. The reader owns personal choice
and momentary observations. This prevents a form from becoming either an empty
generic placeholder or compulsory reader homework.

### Reference owns the complete indexes

R owns the generated global resource index, figure/diagram index, professional
contact collection, deployment customization index, glossary, form index,
source notes, and version history. Source registries remain canonical data;
reader-facing tables are generated views.

### Local deployment is a maintained installation

A deployment consists of a selected edition, verified local fields, privacy
decisions, writable supplies, revision information, one tested route, and a
review date. Printing alone does not complete deployment.

### Landing and guide have different domain roles

- `bathroom-emergency.fkr.dev`: project purpose, participation, deployment,
  sources, disclaimers, and release links.
- `be.fkr.dev`: enhanced online guide and downloads.

The local release build describes this contract and performs no publication or
deployment.

## Release output contract

### Master

- A4, A4/2, and A4 large print;
- color and monochrome HTML/PDF for each layout;
- assembled Markdown, editable DOCX, and LaTeX intermediate.

### Standalone

- B, H, T, and R;
- A4, A4/2, and large print;
- color and monochrome Markdown/HTML/PDF bundles;
- graph hub and per-node manifests.

### Project

- self-contained landing package;
- generated reference fragments;
- release manifest with hashes and toolchain;
- no false publish or deploy status.

## Acceptance gates

1. Every stable resource ID is unique, correctly typed, append-only, and
   represented in the active or retired registry.
2. Every generated index is current and source-derived.
3. Every required master and standalone artifact exists and is non-empty.
4. Color and monochrome editions retain semantic text and page-count parity.
5. A4/2 and large-print geometry/accessibility checks pass.
6. New figures have adjacent text fallbacks, sources, and monochrome strategies.
7. Landing and deployment documents contain purpose, participation, build,
   sources, disclaimers, guide links, privacy, maintenance, and feedback.
8. Revision metadata includes project/subguide version, layout, mode, commit,
   build date, and the stable guide URL.
9. CI rebuilds and independently validates the complete matrix.
10. Release commit and local tag occur only after the complete gate passes;
    pushing, publication, and deployment remain separate explicit operations.

## Deferred deliberately

- Detaching all content nodes simultaneously: each node still needs equivalent
  source, visual, layout, and accessibility review.
- A full bird-folding tutorial: it needs tested diagrams and usability review.
- Crossword, sudoku, logic, and graffiti packs: they need licensing,
  difficulty, accessibility, and print-density review.
- Real-world mounting recommendations beyond first concepts: prototypes must be
  observed in wet, reflective, narrow rooms before becoming confident rules.
- Mascot saturation: Badger boxes remain occasional authored notes, not a second
  authority channel competing with safety instructions.
