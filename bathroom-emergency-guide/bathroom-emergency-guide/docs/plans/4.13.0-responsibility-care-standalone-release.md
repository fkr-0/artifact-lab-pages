# Bathroom Emergency Guide 4.13.0 — Responsibility and Care standalone release

## Goal

Release A — Responsibility and Care as the tenth standalone family without
creating parallel prose. Improve the canonical chapter so the route begins with
safety, separates responsibility concepts, and carries enough operational
figures and Blue Book links to function as a detached field object.

## Writing pass

- Put safety before verdict, confession, explanation, or blame.
- Separate four clocks: live harm, continuing effects, repair, and ongoing care.
- Clarify that telling, apology, repair, consent, authority, and forgiveness are
  related but not interchangeable.
- Distinguish support from control when another person can decide.
- Make ongoing care visible as a continuity system with an owner, backup,
  warning signs, essential facts, and a review point.
- Keep emergency, medical, safety, legal, veterinary, and professional routes
  explicit when they own the next action.

## Visual set

Add four authored, monochrome-safe operational figures:

1. `responsibility_clock_map` — choose the live-harm, continuing-effects,
   repair, or ongoing-care clock;
2. `repair_sequence` — stop, stabilize, tell, repair, and follow up;
3. `consent_authority_boundary` — support, refusal, uncertain capacity, and
   immediate-danger boundaries;
4. `care_continuity_loop` — essentials, warning signs, owner, backup, and next
   review.

The existing Vega reproductive-denominator figure remains the quantitative
context figure. Every figure must have complete adjacent prose, direct labels,
position/number encodings, a stable figure address, and paired Blue Book forms.

## Template and support links

Reuse the canonical Blue Book rather than adding a parallel A worksheet family.
A should link to the emergency call, location/access, local contacts,
five-minute values, essential-care continuity, household continuity, and
remarks/handoff forms where relevant.

## Standalone contract

- Build A from `src/chapters/02-situation-a.md` only.
- Include one page-zero emergency gate, one edition contract, a local resource
  map, graph handoffs, and generated Sources and limits.
- Require at least five local sources and five owned reader visuals.
- Add A to the graph hub, site catalogue, release manifest, coverage matrix,
  migration checks, and complete build matrix.
- Expand the standalone matrix from 54 to 60 PDFs.
- Leave no master-only graph node.

## Stable-reference rule

Existing public references must not be renumbered or retired by prose edits.
New headings and figures receive new addresses. Wording improvements to an
existing resource retain its original key when needed.

## Release gate

- Regenerate all inventories and indexes.
- Build six master editions and all 60 standalone PDF editions.
- Verify A source, figure, form, support, graph, and encapsulation metadata.
- Pass tagged-PDF, semantic parity, colour/mono parity, geometry, density,
  accessibility, overflow, site, browser, and complete-matrix checks.
- Inspect generated A figure rasters and representative A PDF pages.
- Record exact-revision evidence before creating an annotated local tag.
- Do not push, publish, deploy, or run the prepared Pages workflow.

## Evidence boundary

The release can prove canonical extraction, source and figure attachment,
rendering, accessibility, and package integrity. It cannot prove legal
liability, clinical capacity, successful repair, service availability, consent,
forgiveness, or performance under a real emergency or family conflict.
