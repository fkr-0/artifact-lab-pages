# Bathroom Emergency Guide 4.5.0 — Roadmap and Milestones

Status: release candidate
Depends on: 4.4.2 manifest and Vega foundation
Release principle: migrate by proven vertical slices, not by directory renaming.

## North-star outcome

Version 4.5.0 ships a graph-linked family in which the master guide remains one
coherent document and at least two subguides can also be built independently
with their own orientation, contents, handoff, and Sources and limits pages.

The release candidate reaches that outcome with **B — Alarm and Calm** and
**H — Air, Smell, and Environment**. The other seven core nodes remain available
in the master and graph hub until each passes the same standalone gates.

## Global constraints

- one emergency gate in the master; one on standalone page zero;
- code + pattern + glyph identity, with colour only as an additional channel;
- canonical prose has one owner;
- local source sections are generated from the canonical registry;
- every quantitative chart has a table fallback and practical limit;
- no release phase multiplies unreviewed outputs faster than validators;
- A4/2 remains a first-class target, not a scaled afterthought.

## Milestone stop rules

Stop and revise when any of the following occurs:

- standalone and master prose begin to diverge;
- a new source section is handwritten instead of generated;
- output count grows before parity checks exist;
- a visual needs colour to remain interpretable;
- a subguide repeats the generic emergency gate inside the master;
- a proposed satellite lacks a distinct reader question, two graph edges, source
  ownership, or enough content for a useful 8–20 page object.
