## Purpose

4.3.1 is a bounded maintenance patch. It corrects navigation and release
integrity discovered while freezing 4.3.0. It does not implement the planned
standalone graph/subguide renderer, add a new locale, or reopen the safety
architecture.

## Included work

- Rename the mixed situation chapter from B–G to B–F.
- Keep Situation G as a clearly named handoff and standalone chapter.
- Update density markers, roadmap language, and generated references.
- Reject stale “six kinds” or ambiguous B–G master labels in validation.

### 2. Release and script integrity

  metadata aligned at 4.3.1.

  accidentally committed as ordinary files.

  the deliberate version-history chapter.
