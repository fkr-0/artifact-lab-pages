# 4.3.1 Sparse-Page Review

Reviewed: 22 July 2026
Output: `build/pdf/guide.pdf`, 88-page standard A4 candidate
Method: renderer density report, extracted page text, chapter-boundary inspection,
and comparison with A4/2 and large-print outputs.

## Decision rule

A sparse page is not automatically waste. Space is retained when it performs one
of these jobs:

1. leaves room to write;
2. protects an urgent sequence from unrelated material;
3. marks a meaningful subguide boundary;
4. presents a final handoff or route map;
5. prevents reference/history material from colliding with the next subject.

Space is removed only when it is an accidental pagination remainder with no
reader function.
